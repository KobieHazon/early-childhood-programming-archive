# Early Childhood Programming Archive

A collection of my early programming projects.

## Project Summary

This repository consolidates representative childhood-era programming artifacts in one archive.

## Contents

- `csharp/` contains selected early C# WinForms projects: arithmetic utilities, numeric checks, text checks, and table generation.

## Tech Stack

- C# WinForms projects from the Visual Studio Express era
- Hand-written static HTML

## Validate

Run:

```sh
make check
```

The check is static. It confirms representative C#/HTML files are present and scans tracked text for privacy and machine-path markers. The old Windows/.NET Framework environment was not available during validation.
